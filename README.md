# Фэн-шуй: расчётный движок циклов

**Статус проекта: MVP / экспериментальное расчётное приложение. НЕ production-ready.**

Браузерное приложение для традиционных китайских циклических расчётов
с архитектурой, управляемой данными (JSON-driven).

Независимая реализация. Референс для функциональной и визуальной модели —
программа «Фэн-Шуй Удачи» (В. Дегтярёв, feng-shui.net.ru). Код референса
не использовался и недоступен; воспроизводится **функциональная эквивалентность
подтверждённых расчётов**, а не чужой исходный код.

---

## Архитектура

```
JSON DATA  →  CALCULATION ENGINE  →  RESULT MODEL  →  CHART ENGINE  →  UI
 data/*.json    src/engine/*.js      computeProfile   src/chart/*.js  src/ui/*
```

Жёсткое правило: **расчётная логика отделена от интерфейса**.
Ядро (`src/engine`) не обращается к DOM — это проверяется автоматически
(`tools/red-team.js`, проверка 3).

Ключи данных — стабильные латинские ID. Русские названия — только подписи.
Китайские термины хранятся в отдельных полях (`han`). Цвета пяти стихий —
централизованно в `data/elements.json`.

## Возможности

- Китайский солнечный календарь, 24 сезона (по видимой долготе Солнца)
- Небесные стволы, земные ветви, Инь/Ян, пять стихий
- Четыре столпа (Ба-цзы) со скрытыми небесными стволами
- Столпы удачи (大運) и столпы текущей даты
- Взаимодействия: слияния стволов, шесть слияний, треугольники, сезонные группы,
  столкновения, вред, наказания (три-, двух- и самонаказания)
- Три Ша, Тай Суй, Суй По
- Летящие звёзды Сюань Кун: земная основа, горные и водные звёзды,
  звёзды-гости года, месяца и дня, 24 горы, периоды Сань Юань
- Число Гуа, восемь домов, благоприятные и неблагоприятные направления
- Проекция силы стихий на 12 меридианов, индекс гармоничности, сумма Инь/Ян
- Графики в четырёх временных масштабах: десятилетия, годы, месяцы, дни

## Быстрый старт

```bash
npm run build      # сборка JSON-пакета и автономного HTML
npm run serve      # http://localhost:8080
npm test           # статические + модульные + интеграционные тесты
npm run test:browser
node tools/red-team.js
npm run dist       # ZIP-пакет
```

Зависимостей нет — только Node.js ≥ 20 и браузер.

## Статусы алгоритмов

Каждый расчёт помечен: `VERIFIED` · `PARTIALLY VERIFIED` · `INFERRED` · `NOT VERIFIED`.
Статусы видны в интерфейсе и попадают в экспортируемый JSON.

**Подтверждено (VERIFIED):** юлианская дата, долгота Солнца, столпы года/месяца/
дня/часа, взаимодействия, полёт звёзд и построение трёх карт, годовая и месячная
звёзды, число Гуа, Три Ша / Тай Суй.

**Частично (PARTIALLY VERIFIED):** моменты солнечных терминов (±15 мин),
дневная звезда (конфликт источников), возраст старта столпов удачи,
веса скрытых стволов.

**Выведено нами (INFERRED):** весовая модель силы стихий, перевод стихий
в силу меридианов, индекс гармоничности, коэффициент трансформации при слияниях.

> Формула, по которой референсная программа получает числовые значения
> меридианов, **не опубликована и не восстановлена**. Наша модель — явная
> декларированная гипотеза (`data/weights.json`), а не реконструкция оригинала.
> Форма графиков меридианов поэтому **не обязана совпадать** с референсом.

**Не реализовано (NOT VERIFIED):** «Индикатор Удачи», «Деятельность», эмоции,
воля, дух, социальные показатели, замещающие звёзды (替卦), уравнение времени,
историческая база часовых поясов. Причина: восстановить алгоритм невозможно,
а выдумывать его запрещено доктриной проекта.

Подробнее: [`docs/ALGORITHMS.md`](docs/ALGORITHMS.md),
[`docs/CONFLICTS.md`](docs/CONFLICTS.md), [`docs/TESTING.md`](docs/TESTING.md).

## Внешняя валидация

- **594 из 594** значений звёзд на 22 опубликованных геомантических картах
  (периоды 2, 5, 7, 8, 9) с en.wikibooks.org — полное совпадение.
- Долгота Солнца: 199.90894° против опубликованных Meeus 199.90895°.
- Равноденствия и солнцестояния 2025 — совпадение с астрономическими таблицами
  в пределах 20 минут.
- Столп дня: два независимых якоря (2019-01-27 甲子, 2000-03-01 戊午).
- Годовые и месячные звёзды 2026 — совпадение с независимой публикацией.

## Целостность алгоритмов

В расчётном ядре **не используются** `random()`, `noise()`, произвольная
интерполяция, вымышленные точки и подгонка под форму чужого графика.
`sin`/`cos` присутствуют **только** в `astro.js`, где они физически обоснованы
рядом видимой долготы Солнца. Соблюдение проверяется `tools/red-team.js`.

## Ограничение

Показатели меридианов и органов — **традиционные метафизические
(энергетические) расчётные величины**. Это **не медицинская диагностика**,
не медицинский прогноз и не основание для решений о здоровье.
