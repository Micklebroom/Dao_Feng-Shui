# Тестирование

Порядок: **STATIC → UNIT → INTEGRATION → BROWSER → VISUAL QA → RED TEAM**.

Правило проекта: успех **не** объявляется на основании того, что код собрался.

## Запуск

```bash
node tools/validate-data.js     # STATIC
node --test "tests/unit/*.test.js"
node --test "tests/integration/*.test.js"
node tools/browser-test.js      # BROWSER
node tools/standalone-test.js   # автономная сборка
node tools/red-team.js          # аудит доктрины
node tools/qa-report.js         # сводный отчёт
```

## Уровни

### STATIC — `tools/validate-data.js`
10 групп проверок схемы и внутренней согласованности JSON:
статусы и источники; 10 стволов и 12 ветвей с чередованием Инь/Ян; суммы долей
скрытых стволов = 100 %; замкнутость циклов 相生 и 相剋; непрерывное покрытие
360° двадцатью четырьмя горами и по одной триаде на сектор; **магический квадрат
Ло Шу (все суммы = 15)**; 24 термина с шагом ровно 15°; структура взаимодействий
(каждая ветвь ровно в одном треугольнике и одной сезонной группе; столкновения
строго на 180°); все 8 чисел Гуа покрывают 8 направлений без повторов;
нормированность долей меридианов.

### UNIT — `tests/unit/`
- `astro.test.js` — юлианская дата на опубликованных примерах, обратимость,
  пример Meeus 25.a, монотонность долготы, четыре точки 2025 года против
  астрономических таблиц, Ли Чунь 1900–2100, ΔT, детерминизм.
- `ganzhi.test.js` — два независимых якоря столпа дня, правила «пяти тигров»
  и «пяти крыс», поздний час Цзы, обратимость сексагенарного индекса,
  границы Ли Чунь.
- `flyingstars.test.js` — классические раскладки полёта вперёд/назад, периоды,
  годовые и месячные звёзды против независимой публикации, определение горы
  по азимуту, зеркальность карт, перебор 24 гор × 9 периодов.

### INTEGRATION — `tests/integration/`
- `reference-charts.test.js` — **главная внешняя валидация**: 22 опубликованные
  карты Wikibooks (периоды 2, 5, 7, 8, 9), поэлементная сверка горных, водных
  звёзд и земной основы. **594/594 значений совпали.**
- `engine.test.js` — детерминизм, сумма процентов = 100, столпы удачи,
  все четыре временных масштаба, различие режимов «со слияниями»/«без»,
  число Гуа для 1900–2100 (в частности, отсутствие Гуа 5), Три Ша и Тай Суй,
  непрерывность дневной звезды, устойчивость на диапазоне 1900–2100.

### BROWSER — `tools/browser-test.js`
В песочнице нет браузерного бинарника (chromium/firefox отсутствуют, установка
Playwright недоступна). Поэтому реализован DOM/SVG-шим, на котором **реально
исполняются** `src/ui/app.js` и `src/chart/chart.js`.

67 проверок: разбор `index.html`; наличие всех элементов, требуемых `app.js`;
инициализация без исключений; отрисовка 4 столпов, ≥12 линий графика с непустым
`d`, подписей осей, сетки, легенды из 12 меридианов, 9 дворцов Ло Шу; заполнение
таблиц меридианов, удачи, сезонов (24), Гуа (8); интерактивность — клик по
легенде, «все/снять», 4 масштаба, 3 режима графика, пересчёт, смена азимута,
переключатель слияний, вкладки, tooltip; корректность экспорта JSON.

**Честное ограничение:** шим не воспроизводит layout, шрифты и реальный
растеризованный рендеринг. Финальную визуальную приёмку нужно делать
в настоящем браузере.

### STANDALONE — `tools/standalone-test.js`
21 проверка: отсутствие внешних ссылок, инлайн стилей и данных, **исполнение
инлайн-скрипта в изолированном контексте** `node:vm` и повторная проверка
отрисовки и интерактивности уже в автономной сборке.

### RED TEAM — `tools/red-team.js`
17 проверок доктрины: запрет `random`/`noise`/подставных данных в ядре;
тригонометрия только в `astro.js` и только с обоснованием; отсутствие DOM
в ядре (анализируется код без комментариев и строк); отсутствие расчётных
весов в UI; `weights.json` помечен `INFERRED` и содержит предупреждение;
`VERIFIED` только при наличии источников; наличие всех якорей конфликтов,
на которые ссылается код; отсутствие заявлений о production-ready; наличие
медицинского ограничения; детерминированность (ядро не читает системное время);
отсутствие зависимостей.

## История дефектов (BUG → ROOT CAUSE → FIX → TEST → REGRESSION)

### Дефект 1 — полярность звезды 5 (КРИТИЧЕСКИЙ, расчёт)
- **BUG:** карта периода 9 с сидением S2 не совпала с эталоном.
- **ROOT CAUSE:** звезда 5 не имеет дворца в Ло Шу; в коде стояла заглушка
  «всегда лететь вперёд» с комментарием «школы расходятся».
- **АУДИТ:** найдено правило — полярность 5 берётся по номеру периода
  (Wikipedia, Alchetron), численно подтверждено картами Wikibooks.
- **FIX:** заглушка удалена; при отсутствии периода функция бросает ошибку,
  а не возвращает молча неверный результат.
- **TEST + REGRESSION:** 22 эталонные карты, 594/594 значений.

### Дефект 2 — порча кода автономным сборщиком (КРИТИЧЕСКИЙ, сборка)
- **BUG:** `SyntaxError: Identifier '$' has already been declared` в
  автономном HTML; веб-версия при этом работала.
- **ROOT CAUSE:** `String.prototype.replace` со **строкой** замены трактует
  `$$` как литерал `$`; идентификатор `$$` в `app.js` превращался во второй `$`.
- **FIX:** все замены переведены на функции-заменители, добавлен комментарий.
- **TEST + REGRESSION:** `tools/standalone-test.js` исполняет собранный файл
  в `node:vm`; проверка `grep -c 'const \$\$ ='` = 1.

### Дефект 3 — ложное срабатывание аудита
- **BUG:** red-team сообщал о DOM в `ganzhi.js`.
- **ROOT CAUSE:** подстрока `document` в английском слове «documented» в комментарии.
- **FIX:** перед сканированием удаляются комментарии и строковые литералы;
  шаблоны уточнены до `document.`, `querySelector(` и т. п.

### Дефект 4 — DOM-шим не понимал атрибуты без значения
- **BUG:** browser-test не находил `#chk-combos`, `#chk-year`, `#chk-month`.
- **ROOT CAUSE:** регулярное выражение парсера требовало `имя="значение"`,
  а `checked` идёт без значения — тег не распознавался целиком.
- **FIX:** поддержка атрибутов без значения и без кавычек.

### Дефект 5 — слишком строгая граница в тесте
- **BUG:** тест столпов удачи падал при `startAge = 10.05`.
- **ROOT CAUSE:** ошибка в **тесте**, не в коде: максимум равен
  30.4 дня / 3 ≈ 10.2 года, а в тесте стояло 10.
- **FIX:** граница исправлена на 10.5 и добавлена проверка, что сумма
  расстояний вперёд и назад равна длине солнечного месяца.

## Что НЕ протестировано (честный список)

1. Реальный браузерный рендеринг (нет браузера в среде) — только DOM-шим.
2. Визуальное сравнение «пиксель в пиксель» с референсом — скриншоты
   референсной программы недоступны для загрузки из песочницы.
3. Значения меридианов не сверялись с референсом: его формула неизвестна,
   сверять не с чем (см. `CONFLICTS.md`).
4. Даты вне диапазона 1900–2100 (движок допускает, но не проверялся).
5. Кросс-браузерная совместимость и мобильные разрешения (интерфейс
   намеренно desktop-only, min-width 1100px).
